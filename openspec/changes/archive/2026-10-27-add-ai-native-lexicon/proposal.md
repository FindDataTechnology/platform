# Proposal: add-ai-native-lexicon

## Why

平台愿景已定调为「客户在我们的系统内打造和经营自己的 AI 智能体集群」，但用户侧命名与之错位：旗舰运行时组织叫「舰队」（用户裁决「舰队在中国没法被理解」），而「集群」一词被占用在动态的会话即席小组上；分发单元 pack 在用户侧同时以「功能集 / AI 能力包 / 我的包 / 套件 / 工坊」至少五种叫法出现。供给开放（vendor-supply-open / market-revenue-share 已立项）之后这些词将印在第三方供应商的上架条目、合同与分成账上——**现在是对外放量前最后一个便宜的统一窗口**。三项词位决策用户已于 2026-10-27 拍板（explore 决议，见记忆 `product-naming-vocabulary-explore`）。

## What Changes

1. **fleet 用户侧全面改称「集群」（en: Cluster）**：web zh-CN / en 两套 locale 中含「舰队 / Fleet」字样的可见文案全部改值；导航、驾驶舱品牌（→ 集群驾驶舱）、trace 徽章、概况页签、种子/模板货架文案随动。**键名 / API 字段 / spec 目录名（agent-fleet-* 等）零改**——只翻可见词（沿用 2026-10-24 词汇老律）。
2. **动态 cluster 改称「阵列」（en: Array）**：创建 / 我的 / 详情 / 解散 / 载入（composer 绑定）/ 会话头部运行提示等可见文案改值；「集群」作为常设组织的专属词让位后不再用于即席小组。代码键（`clusters.*` 等）与 API 路径零改。
3. **pack 定词「能力包」（en: Pack），市场定词「能力市场」**：取代「功能集 / AI 能力包 / 我的包」混用；技能 zip 上传物保留「技能包」叫法（它是文件件，不是市场单元）。
4. **市场四类型徽章（蓝图 / 分身 / 助手 / 工具）由 manifest 结构自动推导**：带 fleet/cluster 组织块 → 蓝图；含 facade serving 契约角色 → 分身；有角色无组织块 → 助手；纯技能/MCP 捆绑无角色 → 工具。类型不靠包名后缀背；**供应商命名规约 = 包名自由、不审后缀**，徽章即类型治理的全部。
5. **五枚官方车队种子的显示名改版（下次铸造上架时生效，文件名 / packId 不动）**：公司式舰队→AI 公司、内容工厂舰队→内容流水线、情报站舰队→晨报情报站、投研晨会舰队→投研晨会、客服护航舰队→客服班组（均挂「蓝图」徽章）。存量在售条目 `CRM 客服套件 / 分身工坊 / 寻数分身` 名称不动，分别自动落「工具 / 助手 / 分身」徽章。
6. **CMS 双语图解课程（舰队驾驶舱图解，zh/en 已发布）改版清单**随 tasks 落地——本 change 只产出改版清单与口径，课程重发本身由内容侧执行。
7. **不受牵连**：智语聊天室词汇v3（空间/值守/呼叫/接管）、「AI 分身」口径、（定时运行/产出×交付/流转/结构视图）等已收官终词；历史台账与已归档 spec 不翻坟。

## Capabilities

### New Capabilities

- `native-lexicon`: 平台用户侧命名词典——容器词（集群/阵列）、分发词（能力包/能力市场）、市场徽章推导与供应商命名规约、零改（键/API/目录）与历史冻结两条纪律。这是跨能力的对外口径真源。

### Modified Capabilities

- `pack-marketplace`: 市场条目的类型展示从「无类型概念 / 名称后缀自由生长」改为**四类型徽章 + 结构自动推导**的需求（展示层变化，不改清单/安装/计量语义）。

## Impact

- **web locale**（`web/src/locales/zh-CN/common.json` 及 en 对应文件）：~100 处键的**值**改动，键名零改；快照 CI 的 locale 闸应保持绿（仅值变更）。
- **server**：市场条目查询响应新增 `badge`（或等价字段）及其 manifest 结构推导逻辑；兼容存量条目。
- **docs/fleet-templates/*.seed.json**：5 枚种子的 `name`（显示名）字段在下次铸造时更新；种子文件本身与测试锚点（清单真源断言）需要同批调整。
- **docs**：对外文案口径统一至「集群 / 阵列 / 能力包 / 能力市场」。
- **无 DB schema 变更、无 API 契约破坏、无运行时行为变化**——全部为展示层与文案层。
- 关联在途 change：`add-pack-locale-tracks`（E 改名随本 taxonomy 同批）、`add-vendor-supply-open` / `add-market-revenue-share`（供应商命名规约为其前置口径）。
