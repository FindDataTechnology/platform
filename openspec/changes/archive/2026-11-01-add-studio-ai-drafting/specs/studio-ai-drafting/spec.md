## Purpose

AI 起草是画布的加速器而非自动化：模型产物永远落为**可编辑草稿**，人的「采用」是唯一写入三桶的门，发射口永远不直接吃模型输出。

## ADDED Requirements

### Requirement: AI 起草只产草稿，不触发射口

起草动作调用既有 builder 工具面（经鉴权 HTTP 桥），产物必须（SHALL）只填充画布草稿态；预设/pack 草稿/舰队/蓝图四个发射口在起草路径上零调用。

#### Scenario: 起草后无发射产物
- **WHEN** 用户触发 AI 起草并等待完成
- **THEN** 画布出现可编辑草稿，且预设、pack 草稿、舰队、蓝图均无新增（测试断言无写调用）

### Requirement: 人的采用是唯一写入门

未点「采用」前，草稿必须（SHALL）不覆盖现有三桶内容；取消采用后工作文档逐字段不变。

#### Scenario: 取消采用零污染
- **WHEN** 用户起草后点取消
- **THEN** 工作文档与起草前逐字段相等

### Requirement: 桥走既有鉴权与白名单

HTTP 桥必须（SHALL）按调用方身份走既有鉴权与 tool_risk 语义；只暴露起草类工具，白名单外工具名被拒。

#### Scenario: 白名单外工具被拒
- **WHEN** 经桥请求执行/发射类工具
- **THEN** 桥拒绝且不触达 MCP
