## MODIFIED Requirements

### Requirement: 工作室提供编辑→校验→diff 的工作面，草稿不落库

平台 SHALL 在 owner 面提供蓝图创作工作面，由 **Agent Studio 的团队模式**承载（不再设独立的蓝图构造间页面）：蓝图创建与编辑（表单与 JSON 双轨，互相只读同步，不绕校验；三桶段经三桶卡编辑，蓝图专属段经表单编辑）、以自然语言生成蓝图草稿（**承袭构造师 pack 的编译能力**，仅作为草拟输入渠道，不引入第二个编译源）、草稿先经完整校验链与归一化 diff 再呈现给主人。**未经主人明确批准前，经面不得将草稿落地为任何实体**：市场上不出现新包、市场与铸造仓不出现新 manifest、实例化路径不出现新集群。

#### Scenario: 草稿先行、批准未至零落地

- **WHEN** 主人提交 NL 场景并产出的蓝图草稿尚未批准
- **THEN** 市场条目、铸造仓与集群库无任何新增；工作台只显示草稿与 diff

#### Scenario: 双轨编辑不绕校验

- **WHEN** 主人以 JSON 轨直接改岗位编制
- **THEN** 提交前该剧字段仍跑全套既有校验；直写不得绕过校验闸

#### Scenario: 团队模式承载蓝图专属段

- **WHEN** 主人在 Agent Studio 团队模式编辑一份蓝图的 boundary/dataSources/判据模型
- **THEN** 这些蓝图专属段在团队模式内可编辑并随文档一起过完整校验链，且三桶段仍经三桶卡编辑
