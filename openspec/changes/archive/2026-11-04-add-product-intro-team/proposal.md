# add-product-intro-team

## Why

要一支**对外介绍公司产品**的智语给外部人用（用户 2026-10-30 提出）。盘点结论：

- **没有现成的**：官方五枚团队种子（AI 公司/内容流水线/晨报情报站/投研晨会/客服班组）全部是内部运营或行业场景向，市场 89 包里也没有产品介绍向的资产。
- **零件全齐**：对外通道（智语游客嵌入 widget `/zhiyu/embed/`、join 链接，`add-zhiyu-website-embed` 已上产）空闲；智语房间的 agent 成员车道现成（`gateway/zhiyu` invite kind=agent）；官方种子铸造链与守恒测试（`agent-fleet-templates`「官方种子库守恒」）现成。
- **用户已拍板的决策**：①形态=小团队（前台+产品线分专家，而非单专家）——团队本身就是产品能力的展示；②产品线**五条全上、识律（法律）要主动推**；③与智语空间的接线**等 `add-zhiyu-team-memory` 刀B 上线后处理**（团队部署成员进房间的正经通道），本变更不做任何房间/接线的代码。

## What Changes

- **新官方种子** `docs/fleet-templates/product-intro-fleet.seed.json`：前台「产品向导」+ 五线专家（一Base=壹座集群平台、十Lex=识律法律、百Wire=柏讯数据AI基础设施、千Facet=谦面预设与技能、万Constellation=萬星运行时基础设施）。编导为前台→各专家的 dispatch 星型（会话型团队，无 cron 节奏）。
- **范围归属（用户确认）**：星研（研究/课程）并入前台话术（是内容不是产品线）；永忆（开源自托管）并入一Base 专家叙事（壹座的开源形态）——专家数不膨胀。
- **知识内嵌**：六 persona 内嵌官网级知识（五线定位、一·十·百·千万层级叙事、背书数据：452 指标概念/53 MCP 工具/18 开源仓/三阶段路线图 蝉蜕·卧龙·九天），来源与日期标注在种子头注释。
- **红线清单**：对外绝不出现内部信息（部署史、主机名、成本、网络拓扑、运营数字）与 v3 旧词（舰队/集群/员工框架词——一律 v4 词表：智能体团队/小组/智能体/智能体市场）；红线由自动化测试对种子文本断言。
- **分诊纪律**：前台拥有跨线关系问答（一·十·百·千万层级）并**显式把法律相关询问导向识律专家**（用户裁定要推法律线）；识律 persona 承载完整法律产品叙事。
- **不做**：多语言 en 副轨（`add-official-packs-i18n` 另案）；营销转化追踪；智语房间/嵌入机制的任何代码改动（接线是后续配置+刀B 依赖）；知识检索集成（v1 知识内嵌 persona）。

## Capabilities

### New Capabilities

（无——官方种子落在既有 `agent-fleet-templates` 能力的种子库守恒框架内，不新开能力域。）

### Modified Capabilities

- `agent-fleet-templates`: 新增两条需求——①对外介绍种子的内容红线与词表纪律（种子文本级断言：无内部信息、v4 词表、来源标注）；②前台分诊含法律线显式路由。种子库守恒测试自动覆盖新种子的结构合法性。

## Impact

**代码/资产**
- `docs/fleet-templates/product-intro-fleet.seed.json`（新增）：清单真源，随仓分发，守恒测试自动纳入。
- 守恒测试无需改动（遍历种子库目录）；新增一个种子文本断言测试（红线+词表+分诊纪律）。
- 铸造上架走既有链（官方作者，guide 说明卡数据源自种子）——零服务端代码。

**外部依赖 / 排序**
- 接线任务（智语房间邀请成员+游客 widget 深链+官网嵌入挂载点）**闸在 `add-zhiyu-team-memory` 刀B**（用户裁定「等上了处理」）；该变更对房间成员语义的扩展是接线的正道。
- 词表 v4 呈现依赖 `add-agent-teams-first-class` 的 i18n 批次（显示层），种子文本直接按 v4 书写不受影响。

**风险**
- 会话型团队（岗位无 cron 节奏）与现行预校验的兼容性未验证——官方种子全带 cron；若校验强制 cron，按 design 的风险节处理（最小改动优先，不改 spec 语义）。
- 种子内容与官网内容的同步责任——种子头注释标注来源与抓取日期，官网改版时人工同步（无自动管线，明确不做）。
