## REMOVED Requirements

### Requirement: Collections are persisted in the project database and degrade gracefully
**Reason**: Replaced by WeKnora's knowledge base management.
**Migration**: Use WeKnora's UI to create and manage knowledge bases.

### Requirement: Users can create, list, rename, and delete collections
**Reason**: Replaced by WeKnora's knowledge base management.
**Migration**: Use WeKnora's UI at `/weknora` to manage knowledge bases.

### Requirement: Users can add and remove documents to/from a collection
**Reason**: Replaced by WeKnora's document-to-knowledge-base assignment.
**Migration**: Use WeKnora's UI to assign documents to knowledge bases.

### Requirement: Users can list a collection's documents
**Reason**: Replaced by WeKnora's knowledge base browser.
**Migration**: Use WeKnora's UI to view documents in a knowledge base.

### Requirement: Users can query within a collection
**Reason**: Replaced by WeKnora's retrieval and chat features.
**Migration**: Use WeKnora's chat interface to query a specific knowledge base.
