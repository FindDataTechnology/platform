## ADDED Requirements

### Requirement: 每个读面返回值有界且截断必须自证

系统 SHALL 对每个面向 agent 的读面设定返回上限：条数型读面 MUST 把调用方传入的条数参数夹取到实现声明的上限；正文型读面 MUST 对单次返回的正文长度设上限。任何被截断的返回 MUST 在响应中显式声明（截断标记 + 实际总量），并 MUST 给出继续读取的手段（分页游标或显式偏移），不得以看起来完整的形式返回部分内容。跨分区聚合型读面 MUST 有总量帽，其响应体量不得随分区块数线性增长。

#### Scenario: 条数越界被夹取

- **WHEN** 调用方以远超实现上限的条数参数请求一个条数型读面
- **THEN** 返回条数等于上限，响应中带截断标记与总量，调用方可据此判断结果不是全集

#### Scenario: 正文被截断时自证

- **WHEN** 读取的页面正文长度超过单次返回上限
- **THEN** 响应含截断标记与实际总量，并给出继续读取的游标或偏移；同一页在两次分页之间不重不漏

#### Scenario: 跨分区聚合有总量帽

- **WHEN** 一个聚合型读面覆盖的分区块数超过单页容量
- **THEN** 响应只含上限内的分区块，并声明截断与总分区块数

### Requirement: 退役页在读面一致过滤

所有读面（检索、新近列表、正文读取、聚合概览）SHALL 使用同一条「页面是否已退役」的判定。通过 supersede 关系被更新的页取代的旧页 MUST NOT 出现在任何读面，除非调用方显式要求包含历史版本。判定 MUST 在同一次读请求内只计算一次，不得让不同读面给出不同的存活答案。

#### Scenario: 检索面不返回退役页

- **WHEN** 某页已被同主题的更新页 supersede，调用方以检索面查询该主题
- **THEN** 只返回取代后的新页，旧页不出现

#### Scenario: 显式索取历史时可见

- **WHEN** 调用方显式请求包含历史版本
- **THEN** 旧页可见，且被标注为已退役及其取代者

### Requirement: 同一 owner 的多根记忆由一次读取合并返回

当调用方需要同一 owner 下多个根（自有 / 共享 / 历史根）的记忆时，系统 SHALL 支持在一次请求内返回合并结果，而不是要求调用方按根串行多次请求。响应的每一段 MUST 标注其来源根，使调用方能够区分来源并结合自身隔离策略使用。

#### Scenario: 一次请求返回多根

- **WHEN** 调用方在一次请求中指定多个根
- **THEN** 响应含各根的召回内容，且总预算由该次请求统一执行，不因根数增加而倍增

#### Scenario: 来源可辨

- **WHEN** 响应包含多个根的内容
- **THEN** 每条内容都可追溯到其来源根，调用方无需靠顺序推断
