## MODIFIED Requirements

### Requirement: 硬门判定与基线入档

评测 SHALL 在全量场景上做场景级配对比较并输出裁决：**digest 臂显著优于无记忆臂**（两指标的配对胜率与平均分差阈值在 design 定死）即过门（v4 注入线的解锁依据）；标题臂仅作生产现状基线参照，不参与门的判定。每次全量运行的分数、裁决、token 消耗 SHALL 落档（含被评/judge 模型名与场景集版本），构成可回溯的基线序列。S0 生产基线（交接认领率、调用分布）SHALL 与实验指标分列记载，不得混入实验裁决。基线 MUST 绑定两组版本标识：场景集版本与产出该数字的代码版本（构建产物须与源一致），使任意一次历史裁决能被指名复算；若基线与场景集不入库，运行手册 MUST 给出可重放的确切命令与产物位置，且该位置 MUST 足以在无外部上下文时复算裁决。

#### Scenario: 过门裁决可复算

- **WHEN** 拿到一次全量运行的场景级分数明细
- **THEN** 仅凭明细与 design 阈值可复算出相同裁决，无需重跑

#### Scenario: 不过门同样入档

- **WHEN** digest 臂未达显著阈值
- **THEN** 裁决为不过门，分数与差值仍完整落档，作为渲染/召回迭代的对照起点

#### Scenario: 基线可指名复算

- **WHEN** 审计者拿到一条历史基线记录
- **THEN** 可从记录中读到场景集版本与代码版本，并按运行手册给出的命令在相同版本上重放；场景集已更换导致不可复算时，记录 MUST 明确标注该基线不可复现而非沉默陈留

### Requirement: 老 note 深度场景度量蒸馏召回增量

续作评测场景集 SHALL 含不少于 2 个「老 note」场景：期望背景全部存于同 project 按新近排序排名 >5 的 note 页——现 digest 读面（L1 段至多 5 条）不可达、唯蒸馏后经 L2 检索可达的背景。harness SHALL 对该类场景先经真实蒸馏路径（与生产同契约的侧车 /distill 调用）准备种子根，再渲染 digest 臂，并以不经蒸馏的同根渲染为对照；老.note 场景子集上蒸馏臂对现 digest 臂 SHALL 保持不劣（重推导度均值差 ≥1 分），结果记入 continue-baseline。场景集 MUST 含确实满足臂触发条件的场景（注入 note 数超过 L1 段容量），使该门有真实分母；当触发条件在全集中不成立时，裁决 MUST 报告该门为「未运行」并说明原因，MUST NOT 记为通过，也 MUST NOT 被计入整体通过条件。

#### Scenario: 老 note 背景唯蒸馏可达

- **WHEN** 对含老 note 场景的种子根先蒸馏后渲染 digest
- **THEN** 渲染块含经蒸馏产出的对应 L2 条目（背景可达），对照组（不蒸馏）不含

#### Scenario: 老.note 子集不劣门槛

- **WHEN** 以含老 note 场景的全集跑门
- **THEN** 老.note 子集蒸馏臂重推导度均值较现 digest 臂高 ≥1 分，结果入 continue-baseline

#### Scenario: 门未触发时报未运行而非通过

- **WHEN** 全集中没有任何场景的注入 note 数超过 L1 段容量，该门的分母为空
- **THEN** 裁决输出该门为「未运行」并给出原因，整体裁决不因该门而判为通过

### Requirement: 胜率门按头部空间校准

续作评测的全集门 SHALL 承认「无头部空间场景」的存在：期望基线（none 臂）重推导度 ≥4 的场景本无背景需求，digest 臂至多打平，计入胜率分母只会度量场景集构成而非注入价值。重推导度胜率 SHALL 按有头部空间场景（none ≤3）计且 ≥70%；全集 SHALL 另计非劣率（digest ≥ none−1）且 ≥70%；重推导度 avg diff ≥0.5 与 first_step 双门照旧。老.note 深度场景子集门不受影响。基线记录 SHALL 同时保留旧口径（全集胜率）与新口径两套数字。两套口径 MUST 由评测脚本自身计算并在运行输出中逐项可见（含各自分母），不得以人工事后统计替代脚本输出。

#### Scenario: 无头部空间场景不计入胜率分母

- **WHEN** 某场景 none 臂重推导度 = 5（任务无背景需求，digest 至多打平）
- **THEN** 该场景不计入胜率分母，但计入全集非劣率与 avg diff

#### Scenario: 门校准后判定

- **WHEN** 以含老 note 与深 note 场景的全集跑门（如 17 场景、其中 6 个 none ≥4 的构成）
- **THEN** 判定 = avg diff ≥0.5 且有空间场景胜率 ≥70% 且全集非劣率 ≥70% 且 note-depth 门过；两套口径数字均入 continue-baseline

#### Scenario: 两套口径由脚本产出

- **WHEN** 评测运行结束
- **THEN** 运行输出与基线中同时含全集胜率、headroom 校准胜率、全集非劣率三组数字及各自分母，审计者无需重跑脚本或人工统计即可核对
