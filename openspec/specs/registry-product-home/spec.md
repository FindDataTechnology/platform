# registry-product-home Specification

## Purpose
registry 的客户门面：匿名访客在产品域名根路径看到壹座·Packs 的产品介绍与三步使用指引（而非登录墙），并以只暴露公开可用条目的公开摘要端点呈现市场活数据；客户可达面统一壹座·Packs 品牌。

## Requirements

### Requirement: 匿名根路径呈现产品落地页

对产品域名根路径 `/` 的请求，registry SHALL 按会话状态分流：无有效会话的请求返回壹座·Packs 落地页（HTTP 200，不发生登录重定向）；携带有效会话的请求 SHALL 保持既有控制台行为不变。

#### Scenario: 匿名访客打开根路径

- **WHEN** 不带会话 cookie 的客户端请求 `GET /`
- **THEN** 返回 HTTP 200 与落地页内容，响应不重定向到登录路径

#### Scenario: 已登录用户打开根路径

- **WHEN** 携带有效会话的客户端请求 `GET /`
- **THEN** 返回控制台单页应用，根路由与登录后的既有行为一致

#### Scenario: 控制台深链不受影响

- **WHEN** 匿名客户端请求控制台自身的路径（如 `/login`）或 API 路径
- **THEN** 既有鉴权与重定向行为不变（分流仅发生在根路径的匿名请求上）

### Requirement: 落地页内容与镜像解耦

落地页正文（文案、分区内容）SHALL 由部署期资产（ConfigMap 或等价挂载）提供，与镜像内容解耦：仅修改文案不得要求重新构建镜像。落地页 SHALL 包含四要素：一句话价值主张、三步上手指引（逛市场选 pack → 订阅 → 装进环境）、来自公开摘要的市场内容、开发者发布入口。

#### Scenario: 改文案不出镜像

- **WHEN** 运维更新部署期资产中的落地页文案并使配置生效（滚动或热更）
- **THEN** 落地页呈现新文案，且运行的镜像摘要不变

#### Scenario: 落地页四要素齐全

- **WHEN** 渲染落地页
- **THEN** 页面包含价值主张、三步上手指引、市场内容区、开发者入口（各要素有可定位的测试锚点）

#### Scenario: 中文为主呈现

- **WHEN** 中文环境的访客打开落地页
- **THEN** 正文以中文呈现（首期不要求英文全量对译）

### Requirement: 公开摘要端点只暴露公开可用条目

公开摘要端点（`/api/public/summary` 形态）SHALL 允许无凭据访问，返回市场聚合计数与精选条目卡。端点 SHALL 只包含 `public` 且 `enabled` 的记录；任何非公开或停用条目 MUST NOT 出现在计数、列表或任何存在性信号中（沿 public 单条端点的不泄露语义）。精选清单来自部署期策展配置；策展中当前不满足 public+enabled 的条目 SHALL 被静默剔除。

#### Scenario: 匿名拉取摘要

- **WHEN** 无凭据客户端请求公开摘要端点
- **THEN** 返回 HTTP 200，含聚合计数与精选条目卡片，且响应中无任何凭据要求

#### Scenario: 非公开条目不泄露

- **WHEN** registry 中存在 private、按组可见或已停用的条目
- **THEN** 摘要的计数与精选列表均不含这些条目，也无法通过响应推断其存在

#### Scenario: 策展但未公开的精选被剔除

- **WHEN** 策展配置中的某精选条目当前不是 public+enabled
- **THEN** 该条目不出现在摘要中，端点仍正常返回其余内容

### Requirement: 客户可达面品牌为壹座·Packs

控制台客户可达面（登录页、壳、页头、标签页标题）SHALL 以壹座·Packs 作为产品品牌串；语言探测与切换的既有行为不变（中文态显示「壹座·Packs」，英文态显示对应译名）。管理面 SHALL 保持既有语言与品牌设计，不受本变更影响。

#### Scenario: 客户面标题统一

- **WHEN** 打开控制台任一客户可达面（含登录页）
- **THEN** 页头与标签页标题显示壹座·Packs 品牌串（与语言态一致）

#### Scenario: 语言切换行为不变

- **WHEN** 用户在客户可达面切换语言
- **THEN** 品牌串按语言态切换，其余翻译行为与既有 i18n 契约一致

#### Scenario: 管理面不受影响

- **WHEN** 管理员使用管理面功能
- **THEN** 管理面的语言与品牌呈现保持变更前的设计
