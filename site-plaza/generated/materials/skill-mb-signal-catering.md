# mb-signal-catering

## What this is

餐饮行业信号包（谦面·生意体检姊妹件）：食材成本趋势（大商所期货）、商圈活跃度代理（专资办票房）、堂食外卖切换代理（气象台），可选同业密度。每信号标注代理性质；工商类带批次年份与「历史格局非实时」，无注销口径不做关店量。

Catering industry signal pack (Facet · business checkup companion): food-cost trends (DCE futures), commercial-district activity proxy (专资办 box office), dine-in vs. delivery switching proxy (weather bureau), with optional peer density. Every signal is labeled with its proxy nature; business-registration signals carry their batch year and a 'historical pattern, not real-time' note; with no deregistration basis, no closure counts are produced.

- Species: skill (plaza category enum v1)
- Official: no

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>

3. Deployed agent services receive registry skills through the registry supply channel.
