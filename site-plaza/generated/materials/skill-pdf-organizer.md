# pdf-organizer

## What this is

当需要整理法律 PDF 时使用：检测文字层，生成页面索引、整理草稿和下游交接文件，按内容拆分、合并或直接重命名 OCR 后双层扫描件并规范命名；可做旋转与倾斜校正，不做 OCR 或压缩。

Use when legal PDFs need organizing: detects the text layer, generates page indexes, organization drafts, and downstream handoff documents; splits, merges, or renames post-OCR dual-layer scans by content with standardized naming; can perform rotation and skew correction, but does not do OCR or compression.

- Species: skill (plaza category enum v1)
- Official: no



## How to obtain

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>

3. Deployed agent services receive registry skills through the registry supply channel.
