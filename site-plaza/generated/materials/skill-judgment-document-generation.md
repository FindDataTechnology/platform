# judgment-document-generation

## What this is

根据案件事实描述，协调调用8个原子能力，生成格式规范、论证严密的完整刑事判决书。涵盖事实认定、法律适用、量刑推理及文书输出全流程。

Based on a description of case facts, coordinates and invokes 8 atomic capabilities to generate a complete criminal judgment with standard formatting and rigorous argumentation. Covers the full workflow of fact-finding, application of law, sentencing reasoning, and document output.

- Species: skill (plaza category enum v1)
- Official: no



## How to obtain

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>

3. Deployed agent services receive registry skills through the registry supply channel.
