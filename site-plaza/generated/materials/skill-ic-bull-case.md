# ic-bull-case

## What this is

柏讯投委会 · 多头立论。当用户要求对某只股票构建看多论证、写多头观点、准备投委会辩论的多方意见、把证据集收敛成"为什么该买"的最强论证，或作为 ic-adjudication 的立论阶段被调度时使用。本技能不取数、不计算、不裁决——数字只能引用证据集的 evidence_id，论证组织是唯一职责。与 ic-bear-case 对称，空头未发言时不得替对手立论。

- Species: skill (plaza category enum v1)
- Official: no
