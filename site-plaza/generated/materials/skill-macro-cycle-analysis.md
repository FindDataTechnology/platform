# macro-cycle-analysis

## What this is

宏观周期与景气分析。当用户要求判断当前经济周期位置（复苏/过热/滞胀/衰退）、做六域景气扫描（增长/通胀/货币信用/财政/外贸/地产消费）、做领先-同步-滞后指标分层、识别景气拐点、梳理宏观变量到其业务问题的传导链，或做省际补充与国际对比时使用。走柏讯服务端宏观数据，不含收益率曲线与互换分析。

Macro cycle and business-climate analysis. Use when the user asks to locate the current position in the economic cycle (recovery/overheating/stagflation/recession), run a six-domain climate scan (growth/inflation/money and credit/fiscal/foreign trade/real estate and consumption), layer leading-coincident-lagging indicators, identify climate turning points, map transmission chains from macro variables to their business question, or do cross-province supplements and international comparisons. Uses 柏讯 server-side macro data; excludes yield-curve and swap analysis.
