# case-retrieval-report

## What this is

类案检索与裁判规则报告。当用户要检索类案、出案例检索报告、查某类纠纷的裁判规则或裁判倾向、做同案同判分析、找支持某主张的判例时使用。走裁判文书库 + 指导案例库多组关键词换搜，输出含真实案号、法院、裁判日期与 provenance 的检索报告。

Similar-case retrieval and adjudication-rule report. Use when the user wants to search similar cases, produce a case retrieval report, look up adjudication rules or tendencies for a type of dispute, run like-case-like-decision analysis, or find precedents supporting a claim. Runs alternating multi-keyword searches across the judgment-document library and the guiding-case library, and outputs a retrieval report with real case numbers, courts, adjudication dates, and provenance.

- Species: skill (plaza category enum v1)
- Official: no

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>
