# case-discussion-outline

## What this is

AI自动完成的深度案件分析工具，整合前序材料进行四维度自问自答分析、三方模拟法庭演练，最终生成案件提纲。当用户提及"案件讨论"、"案件提纲"、"案件分析"、"模拟法庭"、"案件研讨"等指令时触发使用。立案完成后主动提醒律师执行。

An AI-automated deep case analysis tool that integrates preceding materials to perform four-dimension self-question-and-answer analysis and a three-party moot court rehearsal, ultimately generating a case outline. Triggers when the user mentions instructions such as "case discussion", "case outline", "case analysis", "moot court", or "case review". Proactively reminds the lawyer to run it after case filing is complete.
