# contract-copilot

## What this is

合同起草与审查助手。基于分层分析与四步流程，输出可执行的风险清单、起草骨架、修改建议、推荐措辞和审查意见书，支持批注与修订两种文档处理方式。用户通过飞书或其他 IM 对话发送合同文件并要求审查或起草时，也应使用本 skill，并优先沿原会话回传修订版和审查报告。

Contract drafting and review assistant. Based on layered analysis and a four-step process, it outputs actionable risk checklists, drafting skeletons, revision suggestions, recommended wording, and review opinions, and supports both annotation and tracked-changes document processing. It should also be used when the user sends a contract file via Feishu or another IM chat and asks for review or drafting, with the revised version and review report returned in the original conversation as a priority.

- Official: no
