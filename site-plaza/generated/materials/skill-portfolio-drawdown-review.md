# portfolio-drawdown-review

## What this is

柏讯组合风险 · 回撤与波动体检。当用户要求"看看这个组合的回撤有多深""波动多大""是不是太集中了""和沪深300比怎么样"时使用。产出：组合级指标（最大回撤含峰谷日、年化波动、HHI、前 N 占比、板块集中度、有效标的数）+ 基准对比（超额与跟踪误差）。指标一律来自 fd-quant 计算面，不手算、不预测，缺失如实标注。

- Species: skill (plaza category enum v1)
- Official: no
