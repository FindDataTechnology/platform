# mb-breakeven-calculator

## What this is

盈亏平衡计算器（谦面·个体户）：算月保本流水、保本客流/单量、安全边际、保本天数。每个数字附公式+基数+来源；外部基数取不到即中止该项并明示，不用模型记忆数字填充。

Break-even calculator (Facet · sole proprietors): computes monthly break-even revenue, break-even customer count/order volume, safety margin, and days to break even. Every figure comes with formula + base + source; if an external base cannot be obtained, that item halts and is explicitly stated — never filled with numbers from model memory.

- Species: skill (plaza category enum v1)
- Official: no



## How to obtain

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>

3. Deployed agent services receive registry skills through the registry supply channel.
