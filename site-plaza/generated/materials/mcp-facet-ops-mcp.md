# Facet gateway operations / 谦面网关操作

## What this is

谦面网关的运营面：目录浏览、智能体名片、技能与服务的检索与检查。

Operations view of the Facet gateway: catalogue browsing, agent cards, and skill/service lookup and checks.

- Species: mcp (plaza category enum v1)
- Official: no
- Public tools: 6


## How to obtain

MCP servers are connected, not installed. The public endpoint:

    https://mcp.finddatatech.cloud/facet-ops-mcp/mcp

Connect it where your agent runs: in 壹座 (Extensions → MCP), or in any MCP-capable editor's config. The endpoint speaks the Model Context Protocol over streamable HTTP.
