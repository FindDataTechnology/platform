# litigation-visualization

## What this is

基于Mermaid语法生成诉讼可视化图表（法律关系图、时间轴图、争点树、要件分析图、攻防对抗图、证据链图谱），按总控当前事项记录和复盘台账衔接，生成诉讼可视化报告Word文档（法官版+律师版）。当用户发送客户编号并提及"可视化"、"诉讼可视化"、"制作图表"等指令时触发使用。

Generates litigation visualization charts in Mermaid syntax (legal-relationship diagram, timeline, issue tree, element analysis diagram, offense-defense confrontation diagram, evidence-chain graph), connects with the controller's current-matter record and review ledger, and produces a litigation visualization report as a Word document (judge edition + lawyer edition). Triggered when the user sends a client number and mentions commands such as 'visualization', 'litigation visualization', or 'make charts'.

- Species: skill (plaza category enum v1)
- Official: no
