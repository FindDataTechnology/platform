# trial-scheduling-and-deadline-monitoring

## What this is

当用户需要跟踪、被提醒案件的开庭排期、执行排期、证据提交期限、上诉期限、送达期限、保全续保等各项法定期限时，使用此技能。 典型触发场景包括但不限于： - 提到"上诉期限""证据提交期限""送达期限""保全期限"等关键词 - 增加、修改、询问案件期限时

Use this skill when the user needs to track, or be reminded of, the various statutory deadlines of a case — trial scheduling, enforcement scheduling, evidence submission deadlines, appeal deadlines, service deadlines, preservation renewals, and other statutory time limits. Typical trigger scenarios include but are not limited to: mentioning keywords such as "appeal deadline", "evidence submission deadline", "service deadline", or "preservation deadline"; adding, modifying, or asking about case deadlines.
