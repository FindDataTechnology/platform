# labor-relation-severance-calculator

## What this is

劳动争议案件核心分析工具，覆盖劳动关系三性从属分析、12类争议自动分类、工时制度定性、工资工时问答、经济补偿计算引擎（N/N+1/2N判断+月工资基数+三层封顶）、加班费三档计算、双倍工资计算。当用户发送客户编号并提及"劳动关系认定"、"经济补偿"、"补偿计算"、"加班费计算"、"工资工时"、"发薪日"、"特殊工时"等指令时触发使用。

Core analysis tool for labor dispute cases, covering three-factor subordination analysis of the labor relation, automatic classification into 12 dispute types, working-hours system characterization, wage-and-hours Q&A, an economic compensation calculation engine (N/N+1/2N determination + monthly wage base + three-tier caps), three-tier overtime pay calculation, and double-wage calculation. Triggers when the user sends a client number and mentions instructions such as "labor relation determination", "economic compensation", "compensation calculation", "overtime pay calculation", "wages and working hours", "payday", or "special working hours".
