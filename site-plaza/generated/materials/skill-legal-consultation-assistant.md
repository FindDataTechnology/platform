# legal-consultation-assistant

## What this is

协助律师处理微信渠道法律咨询和线下咨询，提供口语化回复建议、智能反问引导、软性销售植入，并在用户明确要求或总控确认需要时更新复盘台账。支持客户编号识别、咨询入口路由、线下咨询事实补全等功能。

Assists lawyers in handling legal consultations via WeChat and offline consultations, providing colloquial reply suggestions, intelligent follow-up question guidance, and soft-sell placement, and updating the retrospective ledger when the user explicitly requests it or the master controller confirms the need. Supports client number recognition, consultation entry routing, and offline consultation fact completion.

- Species: skill (plaza category enum v1)
- Official: no



## How to obtain

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>

3. Deployed agent services receive registry skills through the registry supply channel.
