# Quantitative compute / 量化计算

## What this is

确定性计算面：技术指标、组合统计、财务比率、估值、市场状态与因子统计，附决策账本。

Deterministic calculations: technical indicators, portfolio statistics, financial ratios, valuation, regime and factor statistics, with a decision ledger.

- Species: mcp (plaza category enum v1)
- Official: no
- Public tools: 50


## How to obtain

MCP servers are connected, not installed. The public endpoint:

    https://mcp.finddatatech.cloud/fd-quant/mcp

Connect it where your agent runs: in 壹座 (Extensions → MCP), or in any MCP-capable editor's config. The endpoint speaks the Model Context Protocol over streamable HTTP.
