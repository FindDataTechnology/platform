# Web fetch (hosted) / 网页抓取（托管版）

## What this is

托管在平台上的网页抓取：取回指定网址内容并转成可读文本。

Hosted web fetch: retrieve a URL's content and convert it to readable text.

- Species: mcp (plaza category enum v1)
- Official: no
- Public tools: 1 · License: MIT · Provider: modelcontextprotocol


## How to obtain

MCP servers are connected, not installed. The public endpoint:

    https://mcp.finddatatech.cloud/eco-mcp-fetch/mcp

Connect it where your agent runs: in 壹座 (Extensions → MCP), or in any MCP-capable editor's config. The endpoint speaks the Model Context Protocol over streamable HTTP.
