# Info stream index / 信息流索引

## What this is

公告、政务与互动平台的信息流索引：按时间取新、条目详情、全文检索与证据定位。

An index of announcements, government updates, and investor-interaction feeds: fetch new items, read details, search, and locate evidence.

- Species: mcp (plaza category enum v1)
- Official: no
- Public tools: 5


## How to obtain

MCP servers are connected, not installed. The public endpoint:

    https://mcp.finddatatech.cloud/fd-info/mcp

Connect it where your agent runs: in 壹座 (Extensions → MCP), or in any MCP-capable editor's config. The endpoint speaks the Model Context Protocol over streamable HTTP.
