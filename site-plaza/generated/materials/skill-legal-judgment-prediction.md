# legal-judgment-prediction

## What this is

根据案件事实描述，综合调用8个原子能力，预测罪名、适用法条、刑期及量刑情节，输出结构化预测报告及置信度评估。

Based on a description of case facts, comprehensively invokes 8 atomic capabilities to predict the charged offense, applicable provisions, sentence, and sentencing factors, outputting a structured prediction report with a confidence assessment.

- Species: skill (plaza category enum v1)
- Official: no



## How to obtain

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>

3. Deployed agent services receive registry skills through the registry supply channel.
