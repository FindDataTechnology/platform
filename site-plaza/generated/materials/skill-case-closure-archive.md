# case-closure-archive

## What this is

在判决/调解完成后，系统化完成案卷归档、案件总结、客户移交、费用结算等结案工作。当用户发送客户编号并提及"归档"、"结案"、"案件总结"、"办案小结"、"案卷移交"、"费用结算"等指令时触发使用。

After judgment/mediation is completed, systematically handles case-closure work including case file archiving, case summary, client hand-over, and fee settlement. Triggered when the user sends a client number and mentions commands such as 'archive', 'close the case', 'case summary', 'case-closing memo', 'file hand-over', or 'fee settlement'.

- Species: skill (plaza category enum v1)
- Official: no



## How to obtain

1. In 壹座 (Yizuo): Extensions → Skills — subscribe from the skills face.
2. Inside editors: skills reach your editor bundled with a pack that references them — install that pack with:

       npx @finddatatechnology/facet install <packId>
