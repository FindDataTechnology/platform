# code2patent

## What this is

从已开发代码项目中提取技术实现证据，围绕候选专利方案生成算法/软件类说明书式技术交底书，并以“权利要求布局卡 → 发明专利初稿”两步法继续生成接近可申报版的中国发明专利起草材料。触发场景包括：读取代码仓库后撰写技术交底书、将人工总结的专利方案映射到具体实现、从代码中挖掘可专利技术方案、为专利代理师准备权利要求布局和发明专利初稿。

Extracts technical implementation evidence from developed code projects, generates algorithm/software specification-style technical disclosure documents around candidate patent solutions, and, via a two-step method of 'claim layout card → invention patent first draft', further produces drafting materials for Chinese invention patents close to a filable version. Trigger scenarios include: writing technical disclosures after reading a code repository, mapping manually summarized patent solutions to concrete implementations, mining patentable technical solutions from code, and preparing claim layouts and invention patent first drafts for patent agents.
