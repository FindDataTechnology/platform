# statistical-inference

## What this is

统计检验与探索性分析。当用户要求做描述统计与分布诊断、选假设检验（t/ANOVA/卡方/非参）、判断两组或城市间差异是否显著、做相关性与配对分析、诊断时序平稳性与单位根、做多重比较校正，或对已有的本地 CSV/表格做探索性分析时使用。走柏讯服务端序列取数，价格类序列走本地 DAAS。

Statistical testing and exploratory analysis. Use when the user asks for descriptive statistics and distribution diagnostics, hypothesis test selection (t/ANOVA/chi-square/non-parametric), significance testing of differences between two groups or cities, correlation and paired analysis, time-series stationarity and unit-root diagnostics, multiple-comparison correction, or exploratory analysis of existing local CSV/tables. Series data is fetched via the 柏讯 server side; price-type series use local DAAS.
