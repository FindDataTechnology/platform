# BaiXun customer operations / 柏讯客户操作

## What this is

柏讯客户面的读取操作：数据浏览与查询、需求单查看、市场订阅查看，以及内容供给的三项检索。

Read-side operations for BaiXun customers: data browsing and queries, request lookup, subscription listing, plus three content-supply lookups.

- Species: mcp (plaza category enum v1)
- Official: no
- Public tools: 22


## How to obtain

MCP servers are connected, not installed. The public endpoint:

    https://mcp.finddatatech.cloud/wire-ops-mcp/mcp

Connect it where your agent runs: in 壹座 (Extensions → MCP), or in any MCP-capable editor's config. The endpoint speaks the Model Context Protocol over streamable HTTP.
