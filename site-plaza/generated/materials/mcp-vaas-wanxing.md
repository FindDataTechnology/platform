# Wanxing generation / 萬星生成

## What this is

语音、图像、视频与封面的生成任务提交与状态查询，附资产库与模型音色目录。

Submit and track voice, image, video, and cover generation jobs, with an asset store and model/voice catalogue.

- Species: mcp (plaza category enum v1)
- Official: no
- Public tools: 17


## How to obtain

MCP servers are connected, not installed. The public endpoint:

    https://mcp.finddatatech.cloud/vaas-wanxing/mcp

Connect it where your agent runs: in 壹座 (Extensions → MCP), or in any MCP-capable editor's config. The endpoint speaks the Model Context Protocol over streamable HTTP.
