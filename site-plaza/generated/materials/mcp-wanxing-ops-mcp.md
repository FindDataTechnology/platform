# Wanxing agent operations / 萬星智能体操作

## What this is

萬星智能体目录的浏览与名片读取，调用方管理、启停，以及发起一次对话回合。

Browse the Wanxing agent catalogue and read agent cards, manage callers, pause or resume agents, and start one dialogue turn.

- Species: mcp (plaza category enum v1)
- Official: no
- Public tools: 8


## How to obtain

MCP servers are connected, not installed. The public endpoint:

    https://mcp.finddatatech.cloud/wanxing-ops-mcp/mcp

Connect it where your agent runs: in 壹座 (Extensions → MCP), or in any MCP-capable editor's config. The endpoint speaks the Model Context Protocol over streamable HTTP.
