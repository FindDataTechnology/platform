# corporate-fundamental-analysis

## What this is

企业基本面与财务质量分析（柏讯线）。当用户要求给一家 A 股上市公司做三表速览、杜邦分解、现金流质量诊断、财务红旗项排查或同业分位对照时使用。走 GTA firm-year 财务面板 + 中国财报三表与附注，输出带来源与数据期数的可复核结论。本技能只做基本面质量判断，不做估值、不给目标价。

Corporate fundamentals and financial quality analysis (柏讯 line). Use when the user asks for a quick three-statement review, DuPont decomposition, cash-flow quality diagnostics, financial red-flag screening, or peer percentile comparison for an A-share listed company. Draws on GTA firm-year financial panels plus the three main statements and notes of Chinese financial reports, producing verifiable conclusions with sources and data periods. This skill only assesses fundamental quality — no valuation, no target prices.
