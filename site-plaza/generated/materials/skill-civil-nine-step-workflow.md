# civil-nine-step-workflow

## What this is

民事案件九步法会话版（请求权基础 + 要件审判九步法 + 规范说）。当用户描述案情或提供起诉状/答辩状/证据/判决书，要求固定诉讼请求、找请求权基础、抗辩分析、要件拆解、类案检索、争点矩阵、举证责任分配、事实认定、裁判预测或法条/案号真实性核验时使用。输出为纯文本会话推演，不写文件系统、不调脚本。

Conversational version of the nine-step method for civil cases (basis of claim + nine-step element-based adjudication + norm theory). Use when the user describes a case or provides a complaint/defense statement/evidence/judgment and asks to fix the claims, find the basis of claim, analyze defenses, break down elements, search similar cases, build an issue matrix, allocate burdens of proof, determine facts, predict the adjudication, or verify the authenticity of statutes/case numbers. Output is plain-text in-session reasoning; it does not write to the file system or call scripts.
