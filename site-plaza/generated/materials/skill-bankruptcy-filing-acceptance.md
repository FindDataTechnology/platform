# bankruptcy-filing-acceptance

## What this is

覆盖破产申请全流程，包括申请书起草、附件准备、提交跟踪、受理后初步工作。当用户发送客户编号并提及"破产申请"、"重整申请"、"和解申请"等指令时触发使用。

Covers the full bankruptcy application process, including drafting the petition, preparing attachments, submission tracking, and initial work after acceptance. Triggered when the user sends a client number and mentions commands such as 'bankruptcy application', 'reorganization application', or 'composition application'.

- Species: skill (plaza category enum v1)
- Official: no
