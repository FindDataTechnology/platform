# litigation-drafting

## What this is

民商事诉讼文书起草（起诉状/答辩状/证据目录）。当用户提供案情或案件材料，要求写起诉状、答辩状、上诉状要点、证据目录或立案配套文书时使用。法条锚定与类案参照均走真实检索数据源，律师确认要点后才生成成稿。

Civil and commercial litigation document drafting (complaints/defense statements/evidence lists). Use when the user provides case facts or case materials and asks to draft a complaint, a defense statement, key points of an appellate brief, an evidence list, or supporting case-filing documents. Statute anchoring and similar-case referencing both go through real retrieval data sources; the finished draft is generated only after the lawyer confirms the key points.

- Species: skill (plaza category enum v1)
- Official: no
