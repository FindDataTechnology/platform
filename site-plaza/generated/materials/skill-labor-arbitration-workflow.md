# labor-arbitration-workflow

## What this is

劳动争议仲裁全流程（识律劳动法套件入口技能）。当用户描述劳动争议案情（违法解除/经济补偿/加班费/未签合同二倍工资/调岗降薪/工伤待遇）、要求仲裁申请书或答辩书、证据目录、一裁终局判断、仲裁时限表，或以裁判者身份要求争议焦点归纳与裁决说理时使用。按立场（申请人/被申请人/裁判者）推进八阶段流程，并按需点名套件内两个计算器技能。

Full labor dispute arbitration process (entry skill of the 识律 labor law suite). Use when the user describes a labor dispute (unlawful termination/economic compensation/overtime pay/double wages for no written contract/transfer with pay cut/work-injury benefits), asks for an arbitration application or defense statement, an evidence list, a finality determination (one award, final), an arbitration deadline table, or — as the adjudicator — asks for issues to be summarized and award reasoning drafted. Advances an eight-stage process by position (claimant/respondent/adjudicator) and calls the suite's two calculator skills as needed.
