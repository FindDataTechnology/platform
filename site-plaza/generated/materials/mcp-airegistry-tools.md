# AI Registry tools

## What this is

Provides tools to discover and list servers, agents, and skills in the AI Registry. Includes intelligent tool finder which uses semantic search to discover the most relevant tools across all registered services.

- Species: mcp (plaza category enum v1)
- Official: no

## How to obtain

MCP servers are connected, not installed. The public endpoint:

    https://mcp.finddatatech.cloud/airegistry-tools/mcp
