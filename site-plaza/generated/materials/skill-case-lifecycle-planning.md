# case-lifecycle-planning

## What this is

案件全周期规划技能。当用户需要规划案件准备时间线、创建或询问案件准备时间节点、生成案件诉讼路线图和关键时间一览表时触发。典型触发关键词："案件准备""案件准备规划""案件准备时间线""规划案件准备节奏""排开庭"。不处理案件向律师的分配，也不处理与案件管理无关的一般性编程任务。

Case full-lifecycle planning skill. Triggers when the user needs to plan a case preparation timeline, create or ask about case preparation milestones, or generate a litigation roadmap and a key-dates overview table. Typical trigger keywords: "case preparation", "case preparation planning", "case preparation timeline", "plan the case preparation pace", "schedule the hearing". Does not handle assigning cases to attorneys, nor general programming tasks unrelated to case management.
