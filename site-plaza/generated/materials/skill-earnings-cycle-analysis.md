# earnings-cycle-analysis

## What this is

财报周期分析（前瞻 + 复盘）。当用户要求对一家公司做财报前瞻（本次披露类型与时间、该盯哪些科目、超预期/低于预期可能从哪来）、做财报复盘（实际 vs 上年同期、差异由哪个科目驱动、盈利质量如何、对后续季度意味着什么），或梳理连续数期经营动能变化时使用。基于柏讯财报与公告数据，不做技术分析。触发词：财报前瞻、业绩预告、财报复盘、业绩点评、超预期、低于预期、盈利质量、某某公司季报/半年报/年报分析。

Earnings cycle analysis (preview + recap). Use when the user asks for an earnings preview for a company (type and timing of the coming disclosure, which line items to watch, where beats/misses may come from), an earnings recap (actuals vs. the same period last year, which line items drove the difference, how earnings quality stands, what it means for coming quarters), or a mapping of operating momentum changes over several consecutive periods. Based on 柏讯 earnings and announcement data; no technical analysis. Trigger words: earnings preview, results forecast, earnings recap, results commentary, beat, miss, earnings quality, and quarterly/interim/annual report analysis of a given company.
