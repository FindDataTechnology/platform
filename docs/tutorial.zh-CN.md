# 壹座上手教程

> 从「刚拿到账号」到「让它替你干完第一件活」。跟着做一遍大约 10 分钟。
> 想查某个功能而不是从头走，直接翻 [第 7 节·速查表](#7-速查表)。

---

## 0. 先弄明白它是什么

壹座是一个**会动手干活的 AI 工作台**，不是聊天机器人。

区别在这儿：聊天机器人回答问题，壹座**接任务**。你说「审查这份合同的风险条款」，它自己去检索法条、比对条款、把风险分级，最后产出一份可以下载的文档 —— 中间不需要你一步步指挥。

它干完的东西**自动存进「成果」**，不用你手动保存。

**三件事先记住**，后面全部内容都是这三点的展开：

1. **挑对专家** —— 行当对口的专家答得明显更好。
2. **说清需求** —— 像给同事派活，给背景、给样例、说要什么格式。
3. **重要结论要依据** —— 让它给出处，别照单全收。

## 1. 登录

**电脑上**：打开公司给你的壹座网址，点 **Sign in with SSO**（用组织账号登录），用公司邮箱和密码登录。

**手机上**：微信小程序搜索壹座小程序 → 登录页点「扫码绑定」 → 扫电脑屏幕上的二维码。之后手机和电脑是同一个工作台，历史和成果全部同步。

> 第一次登录会跳到身份域的登录页（网址变成 `auth.` 开头），这是正常的，登录完会自动跳回来。

## 2. 第一次配置：选你的工作领域

登录后你会看到一个引导面板：**「你主要用它做什么？」**

这是全篇最值得认真的一步 —— 你选的领域决定了三件事：装哪些行业方案、默认用哪位专家、界面显示哪几项。

### 怎么选

面板上有三张卡片，对应三个已经有配套方案的领域：

| 卡片 | 适合谁 | 会给你装上 |
|---|---|---|
| **法律人员** | 律师、法务 | 法律-合同（合同全流程审查） |
| **股票分析** | 股票研究人员 | 数据-股票 |
| **经济分析** | 经济分析人员 | 数据-中国经济 |

- **最多选三个**，也可以只选一个。选错了随时能改（见第 6 节）。
- 下面有个**选填框**，可以写一句具体想做的事，比如「审查供应商合同」。写了它会记下来，不影响其他配置。
- **现在不想选？** 点「暂时跳过」，界面保持完整不裁剪，之后随时回来配。跳过不会损失任何功能。

### 确认清单

选完点 **「为我配置好」**，你会看到一份清单，写清楚接下来要做什么：

```
安装 法律-合同          ← 要装的行业方案
选定默认助手            ← 把默认专家换成对口的
调整工作面布局          ← 精简界面
```

**这一步只是给你看，还没动手。** 看清了再点 **「启用」**。

### 启用后

界面会立刻变：左侧导航收成四项（对话、资料库、成果、智能体），顶部专家栏换成对口的专家（选法律的话是「合同审查官」）。

> 如果某项**没装上**（比如本部署没有这个方案），完成屏会**如实写出来**，不会假装全都好了。看到提示不用慌 —— 其他项照常配好了，缺的那个之后可以去「智能体 → 行业方案」里自己装。

## 3. 对话：开始派活

### 第一步：确认专家

对话页上方有个选择框，写着当前专家的名字。**首配之后这里已经是对口专家了**，一般不用动。想换就点开挑。

- 「通用助手」什么都能干，但行当不精。
- 专家列表里找不到的，去「智能体」页装。

### 第二步：说需求

像给同事派活一样打字，回车发送。

**文件可以直接拖进输入框** —— 合同、报表、纪要都行。

几个让结果变好的习惯：

| 不要这样说 | 要这样说 |
|---|---|
| 「帮我看看这个」 | 「审查这份合同的风险条款，按高/中/低分级」 |
| 「写个报告」 | 「写一份一页的季度简报，先说结论，再给三个支撑数据」 |
| 「分析一下数据」 | 「对比这三个月华东区销量，找出下滑最严重的品类」 |

**核心是三样：给背景、给样例、说清楚要什么格式。**

### 第三步：取成果

它做出来的图表和文件**自动进「成果」页**。对话过程中也可以在它的回答里点「存入」。

不满意就点**重新生成**；想打断它点**停止**。

> 输入 `/` 会呼出命令菜单，常用的有 `/model`（换模型）、`/new`（开新对话）、`/clear`（清空当前视图）、`/help`（打开帮助中心）。
> 第一次使用会有引导动画，错过的可以在 **帮助（/help）→ 快速上手 → 重看引导** 再看。

## 4. 资料库：让它长期记住

判断标准很简单：

- **这次问完就丢的** → 直接拖进对话框。
- **以后要反复用的**（合同模板、产品手册、制度文件）→ 放进资料库。

在**资料库**页点「添加」上传，或在对话里直接拖文件。支持 PDF、Word 导出的文本、Markdown、网页链接。

上传后它**自动建立索引**。之后你在对话里提问，它会引用这些资料回答**并说明出处** —— 这一点很重要，是它区别于「凭印象瞎编」的关键。

## 5. 成果与自动化

### 成果：它交过的活都在这

每张图表、每份文件按时间倒序排在**成果**页。可以预览、重命名、下载、删除；图表还能「跳到出处」回到当时那轮对话。找不到就用顶部搜索。

### 自动化：让它到点自己干

> **注意**：选了工作领域之后，左侧导航会收成四项，其中**没有**「自动化」和「应用」。
> 不是功能没了 —— 直接访问 `/tasks` 和 `/apps` 依然可用。想让它们回到侧栏，找管理员调整布局。

**自动化**页把「记在脑子里的事」变成「记在系统里的事」：

点「新建」，用大白话描述要做什么、多久做一次 —— 比如「每个工作日早上 9 点，把行业要闻整理成一页简报」。

到点它自动跑，结果存进对话和成果，侧边栏会有小圆点提醒你。任务可以暂停、立刻跑一次、改时间、删除。

**适合放进去的**：周报初稿、每日数据摘要、定期检查某个指标。

## 6. 改主意：换领域、装方案

### 换工作领域

**设置 → 通用 → 工作领域 → 「重新选择领域」**。

面板会带着你当前的选项重新打开，改完提交即可。

> **只会新增，不会卸载** —— 你已经装上的行业方案一个都不会被拿掉。所以放心试，试错没有代价。

### 智能体页的三个标签

1. **专家** —— 所有可用的对话角色，选中即可在对话页顶部切换。下方「我的专家」可以自己组装一个角色：写清楚它是谁、怎么作答、允许用什么技能和工具。
2. **行业方案** —— 一键安装成套的行当组合。比如「识律·合同审查套件」，装完专家列表里就有了。详情页有**使用指南**。装错可卸载。
3. **应用** —— 公司接入的第三方工具面板。（侧栏导航里默认不显示，访问 `/apps` 进入。）

**怎么选**：不确定就先用「通用助手」；发现自己总在重复某类工作（审合同、写周报、盯数据），去行业方案里找对应的包装上。

## 7. 速查表

| 我想…… | 去哪儿 |
|---|---|
| 开始干活 | 对话页，打字回车 |
| 让它记住一批资料 | 资料库 → 添加 |
| 找它做过的东西 | 成果页（支持搜索） |
| 换个专家 | 对话页顶部选择框 / 智能体页 |
| 装行业方案 | 智能体 → 行业方案 |
| 让它定时干活 | 自动化 → 新建（导航里没有？访问 `/tasks`） |
| 换工作领域 | 设置 → 通用 → 工作领域 |
| 换语言/深浅色 | 设置 → 通用 |
| 绑手机 | 设置 → 账户（微信小程序） |
| 看命令和快捷键 | 对话页输入 `/help` |

## 8. 常见问题

**Q：它回答得不好怎么办？**
按顺序试：换对口的专家 → 把需求说具体（给背景、给样例、说格式）→ 把相关文件直接发给它。

**Q：它会乱编数据吗？**
行业方案接的是真实数据源并标注出处，但通用对话仍可能出错。**重要结论务必让它给出依据**，或去「成果」里核对图表数据。

**Q：我上传的文件别人能看到吗？**
看不到。对话、资料库、成果都在你自己的独立空间，与其他用户隔离。

**Q：对话记录会丢吗？**
左侧工作区按对话分组保存，随时点开继续。只有删除才会消失。

**Q：能生成 Word / Excel / PPT 吗？**
装「文档工坊」行业方案，然后直接说「把这份材料整理成 PPT」。

**Q：手机上能看到电脑上的对话吗？**
能。小程序 / App 和电脑登录同一账号，历史、成果全部同步。

**Q：首配时跳过了，现在想配？**
设置 → 通用 → 工作领域 → 重新选择领域。

**Q：想让界面显示完整的导航项？**
首配时点「暂时跳过」就不会裁剪界面，导航保持完整。已经选了领域的话，找管理员调整 —— 布局设置（设置 → 管理 → 布局）只有管理员能改。

## 9. 给新人的三条建议

1. **头一周只干一件事**：找一个你每周都在重复做的活，让它试一次。成了就固化成自动化任务。
2. **别追求一次说对**：它跑偏了就补充背景再说一遍，像带新人一样。
3. **结论要依据**：它能给就让它给，给不出的地方自己核 —— 这是用 AI 的基本功。
