# 从零到第一支智能体团队（公开教程）

> 面向新用户的受众教程：从「不知道装什么」到「第一支团队的首轮报数可读」。
> 全程使用平台现行词表：智能体团队（常驻组织）、小组（会话内临时编组）、
> 智能体（安装单位）、智能体市场（商店）。安装是逐包的显式动作——本文不引导
> 一键全套安装，每一步都由你确认。

## 第 0 步：选一支 starter 团队

六支官方 starter 团队（推荐顺序，帮助中心「开始」路径同款）：

| 顺序 | 团队 | 一句话 |
|---|---|---|
| 首选 | **客服班组** | 恰 3 岗（组长/一线/质检），每 4 小时巡检工单——最小满编、节奏最直观 |
| 进阶示范 | AI 公司 | 全景：CEO 巡视 + 多部门 + 引用岗 + 降级示范 |
| 进阶示范 | 内容流水线 | 主编→策划→撰稿→审校的周流水线，看接棒协作 |
| 领域进阶 | 投研晨会 | 三层级联晨会 + 被动风控岗 |
| 领域进阶 | 晨报情报站 | 双情报员每日巡检，主编 8 点合成晨报 |
| 执行进阶 | **投研交易舱** | 研究→组合→执行→复盘五岗，**模拟盘**：观点变仓位并自己复盘 |

**为什么首选是客服班组**：它最小（恰 3 岗满编）、节奏直观，而且自带平台的
核心示范——CRM 工具未配置时岗位会**如实报「未取得」**，不编造、不整体失败。
你的第一课正好是平台的诚实纪律。

**投研交易舱为什么排最后**：它是唯一会**下单**的一支（模拟盘），门槛也最高。把它放前面，
新手会先撞上"前置项没配好所以什么都不发生"，而新手分不清"没配好"与"坏了"。
它的四条**不行动条件**写在自己的说明卡上：未收到合法权重、风控阈值未配置、风控闸触达、
价格水位过旧——任一成立就零订单并写明原因，不用"上一次的权重"或"空仓即安全"顶替。

### 四个入口分别什么时候用（不是四选一，是四种形态）

市场里和投研交易有关的入口不止一支，按**形态**分工，互不替代：

| 入口 | 形态 | 一句话 | 什么时候用 |
|---|---|---|---|
| 个股投研 / 估值 / 宏观 / 行业 / 轮动等**套件** | 能力 | 给你已有的智能体加手艺 | 你已经有团队，只想让它会做投研 |
| **投研三镜头** | 团队·一次性 | 一个问题三个角度审一遍 | 要拍一个判断，需要多空质询 |
| **投研晨会** | 团队·持续 | 每个交易日出观点 | 要持续盯盘、出晨报 |
| **投研交易舱** | 团队·持续+执行 | 观点变仓位，模拟盘执行并复盘 | 要让观点落到持仓上 |

**升级路径是叠加，不是替换**：装了投研晨会之后再加投研交易舱，两支队**可以并存**——晨会继续
出观点，交易舱把观点变成仓位。两边共用同一套研究能力，多装一支的成本主要在配置，不在重复劳动。

## 第 1 步：订阅并安装

打开 **智能体市场**（导航「智能体」→ 市场页签），搜索团队名
（如「客服班组（官方种子）」），点开详情：

- 说明卡（本页的 usage guide）会告诉你：岗位构成、需要什么凭据、装完先看哪。
- 点 **订阅** → 打开 **设置 → 智能体 → 我的智能体** → **安装**。
  安装取的是该版本的确定性快照——技能、角色、MCP 引用一起到位。

## 第 2 步：实化成团队（生而全队暂停）

安装后在 **应用中心 → 团队模板** 实化。实化不是启动：

- 团队按模板编成岗位树（客服组长 → 一线客服 / 质检员），KPI 槽位与节奏就绪；
- **全队暂停**——这是设计纪律：你先确认组织与节奏，再由你亲手点燃。

## 第 3 步：驾驶舱确认，然后点燃

打开团队的 **驾驶舱**（`/fleets/<团队>`）：

- 组织图上核对每个岗位的在岗者、节奏与 KPI 槽位；
- 需要外部工具的岗位（CRM）可以在连接中心配凭据——不配也行，岗位会如实降级；
- 点 **启动团队**。节奏到点，岗位们开始各自的定时运行。

## 第 4 步：看首轮报数

节奏到点后回驾驶舱：

- 组织卡墙呈现每岗状态环与 KPI 最新值（未决工单、处理件数、首响时长、质检合格率）；
- 日报流呈现各岗最新汇报一行；
- 有疑难事项时，**等你拍板**横幅会亮——组长把同类问题合并成一条请示，不逐单刷屏。

到这里，你的第一支智能体团队已经在运转。往后的路：

- **改组织**：驾驶舱节点检查器内换防/调速/补岗；或对会话里的**团队架构师**说人话。
- **造自己的团队模板**：蓝图构造间把场景编成可上架的蓝图（或找**蓝图构造师**起草）。
- **沉淀团队经验**：岗位回合的关键事实自动进入你的记忆（永忆）——清史重开、
  换防都不丢；团队动态也可以订阅进**智语**空间，和大家一起看、一起讨论。
