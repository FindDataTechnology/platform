# 产物交付在展示层合成：不改写叙述、不自动入藏

对话即交付——产物（图表/文件）的交付主场在对话内，资源库是耐久归档，不是取件柜台。交付件（图表「已入资源库」角标、回合末「本轮产物」文件条带）全部在展示层从既有数据（resources.message_id、tool 块路径）计算渲染，旧会话免费追补，但永不持久化——不写进消息内容、不进模型可见历史，持久化合成会让历史漂移不可逆。镜像时的规范化只动功能性引用（data: URI 链接剥离或替换为平台链接、工作区内绝对路径链接改写为相对），叙述性内容一字不改——正文与内联代码是模型在陈述，改写即伪造。文件入藏维持显式保存边界（add-resource-library 的原设计）：露链不露库，入库是用户的策展行为；自动入藏（含按大小折中）被否决——cron/任务场景下无差别字节拷贝会灌库。模型侧的输出形态约定以「产物契约」经基线技能送达所有角色（含内置 standard 预设）——这是唯一能覆盖默认角色的注入面，人设尾巴路径够不着 standard。
