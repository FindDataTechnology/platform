# 驻留是生命周期，自主是权限；自主行动一律为平台注入的自主回合

Agent 平台的 agent 默认驻留（进程不因闲置回收、上下文跨天连续），但自主行动不是默认——它是按 agent 授予的能力位，且所有自主行动都表现为平台按其声明的工作节奏注入的「自主回合」（发起方是 agent 自身的任务），平台不运行任何 agent 进程内的自由循环。

## Considered Options

- 进程内自由循环（agent 自己决定"继续干"）：真自主，但失控成本无界、dsh 是回合制运行时根本没有此机制、每一步都不可观测不可计费。否决。
- 全员 serverless（维持现状：消息驱动冷启动、30 分钟回收）：与产品目标（长期运行与工作的数字员工）不符。否决。
- 自主默认全员开启：公开平台上每个 agent 都是潜在失控循环，成本与安全模型不可收敛。否决——自主必须是显式授予的权限位。

## Consequences

- 自主回合复用 任务/执行槽 语义与引擎，runner 只需接受"系统注入的回合"这一种新入口。
- 驻留的内存约束（不可回收 ⇒ 内存是第一资源）由温区兜底：超预算退入温区，状态落盘、下次秒级热起。
