# 布局是数据：部署默认→业务角色→用户微调三层解析，部署隐藏终局

页面显隐与结构要从硬编码导航（`NAV_BASE`、settings 分节注册表）变为可配置，以兑现"不同客户切换整体形态"。备选有二：用户开关至上（终端用户自由最大）或部署管控至上。**定案三层解析链**：部署默认定基调、业务角色定工作面形态、用户只做显隐排序微调；且**部署层隐藏是终局的**——用户开关救不回被客户藏起的页面。这是 B 端管控底线，也是客户级布局切换的兑现机制。页面注册表以现有路由 slug 为键（沿用 R1 的"slug 即公开 API"承诺），默认预设等于现状快照，无配置时与硬编码逐项一致，存量 e2e 全绿。

**管辖边界**：v1 预设只管三个容器（一级导航、设置分节、智能体页子页签）；聊天内部面板不进预设。schema 带版本号，将来扩作用面不改数据。
