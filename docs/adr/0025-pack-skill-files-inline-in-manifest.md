# 功能集技能的辅助文件内联进 manifest，而非旁挂 blob 存储

复杂技能（正文+引用文档+脚本）要随功能集分发。备选有二：把 `files` 作为文本对象内联进 pack manifest（manifest 仍是唯一版本快照），或在 facet 侧另建 blob 存储、manifest 只携带引用。**定案内联**：版本原子性零损失——发布、取回、安装、回滚都只碰一个不可变 manifest，无悬挂引用、无 blob 生命周期与 GC；且装包路径「服务端取 manifest→同函数重验→物化」的既有安全不变量原样保留。代价是最坏 manifest ≈21MiB（10 技能×单技能 2MiB 辅文件上限），以读投影（列表/详情只吐路径清单）隔离浏览面来消化。

**退出条件**：当功能集出现数据级附件（模板资产、语料，非文本、百 MB 级）时，内联不再成立，应另立 ADR 改道内容寻址 blob + manifest 引用 + 完整性校验。
