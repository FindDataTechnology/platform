# 首配方案与功能集分立，不做包中包

注册问卷的装配策略（某类新用户进门自动配什么）可以复用功能集承载（"包中包"：把布局、默认专家塞进 pack 清单），或立独立概念。**定案分立**：功能集（Pack）是装进 cell 的版本化资源捆绑，面向订阅者；首配方案（Onboarding Recipe）是面向新用户首配的策展策略，面向平台运营。受众、生命周期、变更节奏皆不同——业务角色比包货架更细（经济/金融/股票三枚角色共享两枚数据包，差别在默认专家与提示卡），塞进 pack 会污染"订阅即获得资源"的干净语义。角色枚举可以先行（admin 分配面可见），问卷只上配方就绪的角色。

**退出条件**：若装配策略将来需要客户自定义并独立分发，再评估是否合并或引入中间层。
