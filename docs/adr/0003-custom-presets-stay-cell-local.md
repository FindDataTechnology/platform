# 自建预设留在 cell 本地，不进市场

自建预设（add-custom-presets）允许用户拼装自己的角色，理论上也可以作为包发布到市场。决定：v1 自建预设是 cell 本地的 DB 行，经 catalog 的用户源进入 picker，**不经市场发布**——市场的创作者门槛、所有权模型、单向冲突政策保持仅对包生效。理由：分享用户预设需要一个尚不存在的创作者身份与审核模型，而本地组合可以诚实地只对本 cell 已装资源解析引用（组合时求交，包卸载自愈）。id 用 `user.` 保留前缀与包角色物理隔离，manifest 校验禁止包角色占用该前缀，历史残留冲突由市场的既有「跳过外来所有者」语义兜底。将来若要分享，走「导出成包草稿」的市场正规路径，而不是给本地预设开发布后门。
