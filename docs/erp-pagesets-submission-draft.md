## 三、演示/审核路径方案（沿 mp-demo-mode / mp-demo-sandbox 同构另立）

- 底座现成机制：`DEMO_BASE` 独立源 + `enterDemoBase/exitDemoBase` 一次性自动进沙箱
  （`src/lib/runtime.ts`、`mp-demo-sandbox` spec：审核员无账号，先体验入口）。
- **同构另立**：为页面集审核单独配一台演示实例（独立后端 + 独立演示租户），`DEMO_BASE`
  指向它；演示租户种四端各一套假数据（演示商品/订单/对账单/运单），与生产租户**零交集**；
  生产 ERP 数据不进审核路径。
- 审核员路径：扫码/搜索进入 → 先体验（沙箱自动接入）→ 四端页面集入口按演示租户授权全量
  可见 → 确认门交互用演示数据走通。演示实例连接器不接真实金蝶/WMS，外部执行状态如实
  标注「演示数据」（Q-B WMS 未定，SP/CP 外部回流面按现状呈现，不伪装）。
