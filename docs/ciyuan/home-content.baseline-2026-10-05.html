快速上手

  1. 注册并登录控制台，支持单点登录；
  2. 在「API Keys」页铸造密钥（sk-…），可设分组与额度；
  3. 参考下方示例发起第一次调用；
  4. 在「用量」页实时查看消耗与余额。
quickstart.sh
# 查看你的密钥可用的模型
curl https://router.finddatatech.cloud/v1/models \
  -H "Authorization: Bearer sk-你的密钥"

# OpenAI 兼容
curl https://router.finddatatech.cloud/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"<上面返回的模型名>","messages":[{"role":"user","content":"你好"}]}'

# Anthropic 兼容
curl https://router.finddatatech.cloud/v1/messages \
  -H "x-api-key: sk-你的密钥" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{"model":"<模型名>","max_tokens":1024,"messages":[…]}'

Agent 服务（萬星）

智能体走 A2A 协议（JSON-RPC over HTTP），同一个 Key 鉴权，按时长×档位计费，失败回合不计费。

GET platform.finddatatech.cloud/api/wanxing/v1/agents
查看公开 Agent 目录

POST /api/wanxing/v1/a2a/{agent}
发起回合

计费与支持

调用即时结算到 Key 余额；余额与消费窗为财务硬顶，不会产生意外账单。常见错误：401 Key 无效 · 402 余额不足 · 429 触发限流。
