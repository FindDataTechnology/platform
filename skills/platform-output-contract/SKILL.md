# 平台产物契约

本平台对"产物"（对话中产生的图表与文件）有固定的服务管道。按以下形态输出，用户才能拿到交付：

## 图表

用 `echarts` 围栏，正文是单个 JSON option 对象：

````markdown
```echarts
{"xAxis":{"type":"category","data":["1月","2月"]},"series":[{"type":"line","data":[3,5]}]}
```
````

- ✅ 这样写：渲染为图表，并**自动存入资源库**。
- ❌ mermaid 围栏、图片文件、表格冒充图表：不渲染、不入库。

## 文件

写文件到工作区后，在正文中用**相对路径** markdown 链接引用：

- ✅ `[年度报告](report.md)`、`[明细数据](data.csv)`
- ❌ `data:` URI 链接（浏览器拦截，且平台会剥除）
- ❌ 只在反引号里贴绝对路径 `/…/workspace/report.md`（用户无从点击）

## 存入资源库

凡以 markdown 链接交付的文件，**同一回合内**调用 `save_to_library` 工具把它存入资源库（参数是相对路径数组，单次最多 10 个）：

- 平台的自动捕获认不出脚本内部写出的文件，显式保存是可靠途径。
- 重复调用无害：相同内容会被去重并回报"已在资源库"；拿到 saved / already-saved 结果后**不要再为同一内容重调**。
- 工具会逐路径回报结果，转述给用户即可（拒收会带原因，如超过 20MB 上限）。

## 交付话术

- 工作区文件**平台会自动交付**给登录用户（预览、下载、存入资源库）。
- 因此：不要说"我没有网络发布能力，无法给下载链接"——链接就是相对路径 markdown 链接。
- 不要指引用户去任何你未被告知存在的面板、按钮或页面；不确定入口时，直接给相对路径链接即可。
